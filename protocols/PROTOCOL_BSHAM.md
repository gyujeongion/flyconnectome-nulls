# 사전 등록 — 경계 표적·지름길 없는 가짜 재배선 (2026-09-24, 실행 전 동결)

엔진 `evo_bsham.py` — 해시 앞 16자리는 연구 로그 54에 기록. `evo_dose.py`(dc27fa100d16d8a7)에서 세 가지만 바꿨다(엔진 머리말에 명시): 경계 가짜 조건 BS<pct> 추가, 진짜 엘리트 저장, 마지막 세대 엘리트의 새 세계 평가.
분석 `analyze_bsham.py`, 드라이버 `run_bsham.sh` — 해시는 연구 로그 54.

## 계기
용량-반응 실험의 가짜 재배선(SHAM)은 연결 수와 교환 횟수를 맞췄지만, 냄새 수용체 출력과 하행 입력이라는 **경계 간선을 건드리지 않았다**. 그래서 "지름길이 원인"과 "경계 근처를 재배선한 것이 원인"이 분리되지 않는다(외부 AI 검토 2건이 공통 지적, 연구 로그 53). 이 실험은 그 둘을 분리한다.

## 조건 (섬 9개 × 512, `--pop 4608 --conds A,AS1,AS3,AS5,AS10,BS1,BS3,BS5,BS10`)
- A: 커넥톰. AS1·AS3·AS5·AS10: 용량-반응 실험과 같은 지름길 이식(냄새→하행 직결 비중 1·3·5·10 % 이상).
- BS<pct>: 같은 실행의 AS<pct>가 쓴 교환 횟수만큼 **회전**을 한다. 한 회전은 AS 교환 한 번과 같은 두 경계 간선(냄새 수용체→X, X는 하행 아님; Y→하행, Y는 감각 아님)에 내부 간선 하나(Z→W, Z는 감각 아님, W는 감각·하행 아님)를 더해 도착지를 돌린다: 냄새→W, Y→X, Z→하행. AS 교환(냄새→하행, Y→X)과 다른 점은 냄새 가중치가 하행 대신 내부 그룹에 떨어지고, 하행 그룹이 Z의 가중치를 받는다는 것뿐이다. 입·출 연결 수와 부호 보존, 지름길 비중 불변을 엔진이 확인하고 어기면 멈춘다. Z→W는 무작위 후보 64개 중 |가중치|가 |냄새→X|에 가장 가까운 것.
- 사전 점검(시드 0, 결과 지표 안 봄): BS1·3·5·10이 17·31·46·100회전 모두 완료, 지름길 비중 0.0001 불변, 연결 수 보존, 하행이 받는 가중치 / 원래 냄새 가중치 중앙값 0.97~1.00.

## 설계
- 생태 P0T0·P1T0, 시드 0~9, 600세대, 개체군 4608, global 보정, `run_dose.sh`와 같은 인자(`--ptox0 0 --probe_ptox 0 --gain_bad 0.25 --tox_curriculum 0 --migrate_every 0 --probe_every 50 --probe_reps 8`). 실행 이름 `bsham_P{0.0,0.2}_T0.0_s{0..9}`.
- 기계: 집 맥스튜디오(M2 Max) 한 대에서 한 번에 한 실행, 실행당 약 90분, 20실행 ≈ 30시간. 모든 조건이 한 실행 안에서 같은 세계 흐름을 공유하므로 비교는 실행 안에서 짝지어진다.

## 종점
- 공통정원 probe의 마지막 기록(550세대) 적합도 — 지금까지의 모든 격자와 같은 종점.
- 새 세계 평가: 599세대 엘리트 상위 16개(진짜 엘리트)를 새로 생성한 세계 4벌(시드 10001~10004, 각 8생애)에서 평가한 적합도의 평균.
- 시드 평균 = 시드마다 두 생태의 값을 평균, n = 10. 평균의 백분위 부트스트랩 90 % 구간(10,000회, 난수 시드 12345) — 용량-반응 분석과 같은 방식.

## 판정 규칙
- **P (1차)**: 시드 평균 AS10 − BS10(마지막 probe).
  - 90 % 구간 하한 > +0.10 → **지름길 특이적**: 같은 경계 간선을 같은 횟수로 바꿔도 지름길이 없으면 효과가 재현되지 않는다.
  - 90 % 구간이 ±0.10 안 → **경계 재배선으로 충분**: 효과는 지름길이 아니라 경계 근처 재배선의 결과로 서술을 고친다.
  - 그 밖 → **중간**: 지름길이 일부를 설명하지만 경계 재배선도 기여한다고 보고한다.
- **R (1차 견고성)**: 같은 대비를 새 세계 평가로 계산해 같은 판정 범주가 나오면 "견고", 다르면 두 결과를 모두 보고하고 주장을 견고하지 않은 것으로 서술한다.
- **S1**: 용량별 차이 AS<k> − BS<k>(k = 1, 3, 5, 10)가 용량에 따라 커지는가 — 시드별 차이에 대한 Page 검정(증가 방향) p < 0.05.
- **S2**: 생태별 AS10 − BS10(기술 통계). **S3**: BS10 − A(경계 재배선만의 효과, ±0.10 기준 기술). **S4**: 후각 절제 비용 AS10 대 BS10. **S5**: AS10 − A 재현(구간 하한 > 0).

## 분석 전 강제 점검
`analyze_bsham.py`는 20실행이 모두 끝났는지, 설정이 실행 이름·시드·포식자 값을 빼고 같은지, 로그의 BS 구성 80건이 모두 완료·지름길 불변·연결 수 보존인지 먼저 확인하고, 하나라도 어긋나면 종료 코드 1로 멈춘다. `--selftest`는 효과 크기를 아는 합성 데이터로 세 판정 범주가 맞게 나오는지 확인한다.
