# 사전 등록 — 학습을 보상하는 생태에서의 배선 비교 (2026-09-22, 실행 전 동결)

엔진 `evo_learn.py` sha256 앞 16자리 `5500b05bfc45db51` = `evo_dose.py`(dc27fa100d16d8a7) + 용량 일치 SHAM + 생태 탐색의 flip_rate 후보 확장 (변경 33줄, 진화·평가 코드 불변). 뇌 데이터 `2781469e0524f33c`.

## 계기

지금까지의 모든 격자에서 커넥톰은 공정한 대조군과 동등하거나 뒤졌고, 어느 조건에서도 연합학습이 검출되지 않았다(논문 §3.7). 우리 해석은 **과제가 학습을 요구한 적이 없다**는 것이다. 냄새가 항상 같은 뜻을 가지면 "냄새 → 운동" 반사가 거의 최적해이고, 후각을 버섯체로 돌리는 커넥톰의 깊이는 순수한 비용이 된다.

초파리 버섯체의 알려진 기능은 맥락·학습에 따라 같은 냄새의 가치를 바꾸는 것이다. 그 기능을 요구하는 생태에서 같은 비교를 하면 결과가 달라지는지 본다.

## 과제 낚시 방지 (이 등록의 핵심)

"커넥톰이 이길 때까지 생태를 바꿨다"는 비판을 세 겹으로 막는다.

1. **생태 선택이 배선을 보지 않는다.** 생태는 `--ecosearch`가 고른다. 이 탐색은 **뇌를 끈 채** 손으로 짠 참조 정책 7종(noEat·reflex·sickStop·twoMem·localSearch·trapline·oracle)만 돌려 점수를 낸다. 점수에 커넥톰도, 대조군도 들어가지 않으므로 선택이 특정 배선에 유리하게 편향될 수 없다.
2. **선택 규칙과 관문을 숫자로 먼저 고정하고 스크립트가 계산한다.** 아래 §2·§3의 식이 전부이며, 결과를 본 뒤 눈으로 고르거나 기준을 바꾸지 않는다.
3. **예측이 틀려도 그대로 싣는다.** 직전 등록(`PROTOCOL_DOSE.md`)에서 D2가 기각됐고 기각으로 보고했다.

## 1. 생태 탐색

```
./venv/bin/python evo_learn.py --homeo global --seed 0 --ecosearch 300 --run ecosearch_learn
```

`FLIP_CANDIDATES = (0.0, 0.002, 0.005, 0.01)`. 후보 300개 × flip 4단계. 뇌를 끄고 256개체로 돌리므로 가볍다. 출력은 `runs/ecosearch_learn/ecosearch.jsonl`.

`flip_rate`는 수명 도중 좋은 냄새와 나쁜 냄새의 정체가 무작위로 뒤바뀌게 한다(엔진 630행). 고정 반사로는 풀 수 없고, 현재 어느 냄새가 좋은지 추적해야 한다.

## 2. 생태 선택 규칙 (동결)

```
제약  (전부 만족해야 후보)
  C1  에너지 구멍 없음:  E0 - c_base*T <= -0.1          (엔진이 이미 강제)
  C2  최고 학습정책 생존율 >= 0.5                        learner_surv >= 0.5
  C3  reflex 정책 생존율  >= 0.3                        reflex_surv  >= 0.3
  C4  flip_rate > 0                                     (학습을 요구하는 생태만)
  C5  learn_margin >= 0.3                               (학습이 실제로 이득이어야 함)

선택  제약 통과 후보 중 learn_margin 최대 1개
      learn_margin = max(twoMem, localSearch, trapline) - max(noEat, reflex, sickStop)
동점  ecosearch.jsonl에서 먼저 나온 행
```

C3가 있는 이유: 반사 정책이 몰살하는 생태는 난이도가 아니라 치사율 문제이고, 그런 곳에서의 비교는 학습 여부가 아니라 생존 하한을 재게 된다.

C5가 있는 이유(2026-09-22 리허설에서 추가): 축소 탐색(후보 8개)을 돌려 보니 제약을 통과한 후보들의 `learn_margin`이 전부 음수였고, "최대값 선택" 규칙만으로는 **가장 덜 나쁜 음수**가 뽑혔다. 학습이 손해인 세계에서 배선을 비교하면 이 실험의 목적 자체가 사라진다. 문턱 0.3은 논문의 동등 범위 δ=0.10의 3배로 잡았다 — 우리가 이미 "차이 없음"이라 부르는 크기 안의 이득을 "학습이 보상된다"고 부르지 않기 위해서다.

**어떤 후보도 C1~C5를 통과하지 못하면 탐색 실패로 기록하고 본 격자를 돌리지 않는다.** 그 경우 대체 격자로 간다. 문턱을 낮추거나 제약을 풀지 않는다.

선택된 `cfg`(npatch·badfrac·bite·bite_bad·gain_good·gain_bad·c_base·sig·T·E0·regrow·regrow_time·flip_rate)를 그대로 `results/learn_eco.json`에 박제하고 이후 전 단계가 그것만 쓴다.

## 3. 파일럿과 관문 (동결)

선택 생태, 시드 0, **500세대**, 조건 `A,N2,AS10`, pop 1536. 이어서 250세대 엘리트에 assay를 걸어 반전 블록까지 측정한다.

세대 수를 500으로 잡은 이유(2026-09-22 확정): 엔진은 엘리트를 `gen % 250 == 0`에서만 저장하므로 더 짧은 파일럿은 assay가 읽을 체크포인트를 남기지 않고, **과학적 이유가 아니라 장부상의 이유로** 관문이 실패한다. pop 1536·3조건이라 약 28분.

### 관문 지표

```
I(c) = [ (reversal − reversal_noplast) − (base − base_noplast) ] / base
```

가소성이 **반전 상황에서 추가로** 얼마나 값을 하는지를, 조건 자신의 적합도로 나눠 생태의 눈금에서 자유롭게 만든 값이다. 이게 논문이 쓰는 연합학습 지표다.

**가소성 차단 비용 자체는 관문으로 쓸 수 없다.** 기존 생태에서 그 값을 재 보니 중앙값이 base의 0.15, 최대 0.92였다(관측 220건). 가소성은 이미 쓰이고 있고, 그것으로 관문을 세우면 **연합학습이 없다는 사실이 이 실험의 출발점인 바로 그 생태가 통과한다.**

### 대조군 교정 (`results/gate_calibration.json`)

기존 생태의 dose·ecofix 격자 전체(10시드 × 2생태 × 조건, 관측 **220건**)에서 I(c) 분포:

| | 중앙값 | 90분위 | 최대 |
|---|---|---|---|
| I(c) 통합 | **−0.010** | +0.167 | +0.426 |

중앙값이 0에 붙어 있다. 논문 §3.7의 "어떤 조건에서도 연합학습이 검출되지 않았다"와 일치하며, 이 지표가 그 사실을 실제로 포착한다는 증거다.

### 관문 (둘 다 만족해야 통과)

```
G1  max_c I(c) >= 0.30          대조군 90분위의 약 2배, 최대(0.43)보다는 아래
G2  I(c) > 0 인 조건이 3개 중 2개 이상    단일 조건의 잡음으로 통과하지 못하게
```

두 문턱 모두 **후보 생태가 존재하기 전에** 대조군만 보고 고정했다. 검증: 대조군 런(`dose_P0.0_T0.0_s0`)에 이 관문을 적용하면 G1 = +0.189로 FAIL한다 — 즉 통과가 자동이 아니다.

**통과 못 하면 §4를 실행하지 않는다.** 연합학습이 대조군 수준을 못 넘는 생태에서 배선을 비교하는 것은 기존 격자를 다시 도는 것과 같다. 그 경우 대체로 보정 격자(`ecofix_P0.0_T0.0`, `ecofix_P0.2_T0.0`) 시드 10~19를 돌려 기존 음성 결과의 구간을 좁힌다.

## 5. 사전 예측

- **L1 (주)** 지름길 보유 조건(N1·N2·AS10)의 커넥톰 대비 우위가 기존 생태보다 작아진다.
  검정: 조건별로 (신생태 우위 − 기존 생태 우위)를 시드 짝지어 계산하고, 세 조건을 Holm 보정. 셋 중 **둘 이상**에서 90% 부트스트랩 구간이 0을 포함하지 않고 부호가 음수이면 지지.
  기존 생태 값은 보정 격자(N1·N2·N4·N5)와 용량 격자(AS10)에서 가져온다.
- **L2** 가소성 차단 비용이 커넥톰에서 지름길 보유 조건보다 크다(짝지은 Wilcoxon, 두 생태 평균).
- **L3** 후각 절제 비용의 조건 간 격차가 기존 생태보다 작아진다.
- **L4 (음성 대조)** 0세대에서는 조건 간 차이가 검출되지 않는다.

## 6. 해석 규칙 (결과를 보기 전에 고정)

| 결과 | 원고에 쓰는 것 |
|---|---|
| L1 지지 + L2 지지 | 지름길의 이점은 과제가 그것으로 충분할 때만 나타나고, 학습을 요구하면 줄어든다. 커넥톰의 구조는 그 요구가 있을 때 값을 한다 |
| L1 지지 + L2 기각 | 지름길 이점은 줄지만 그 이유가 학습은 아니다. 무엇이 줄였는지 모른다고 적는다 |
| L1 기각 | 학습을 요구해도 지름길 우위가 유지된다. 이 모델에서 지름길 이점은 과제 난이도와 무관하다고 보고하고 논문의 범위 한계를 유지한다 |
| 관문 실패 | 이 생태에서 어떤 조건도 학습을 진화시키지 못했다고 보고한다. 본 격자는 돌리지 않았다고 명시한다 |

어느 경우에도 생태를 다시 고르지 않는다. 다시 고르면 그때부터는 탐색이 아니라 낚시다.

## 수정 1 (2026-09-23, 파일럿 실행 후 발견 — 이 등록의 실험은 가설을 시험하지 않았다)

**파일럿은 독이 없는 세계에서 진화했다.** 생태 탐색(§1)은 후보 세계를 점수 낼 때 나쁜 먹이를 전부 독으로 둔다(`evo_learn.py` 922행, `evaluate(..., ptox=np.ones(n))`). `learn_margin 5.405`는 그 세계의 값이다. 그런데 동결된 생태(`results/learn_eco.json`)에는 독 확률이 기록되지 않았고, 파일럿 명령도 `--ptox0`을 넘기지 않아 기본값 0.0이 쓰였다. 엔진은 `ptox0 = 0`이면 나쁜 먹이를 **전부 좋은 먹이로 바꾼다**(`env_init`: 나쁜 먹이는 `uniform >= ptox`일 때 좋은 먹이가 됨). 실측: `pilot_learn_s0`와 `pilot_eta_s0` 모두 `ptox0 = 0.0`, `nbad = 12`.

즉 파일럿 세계에는 독이 하나도 없었다. 좋은 냄새와 나쁜 냄새의 정체가 뒤바뀌어도(`flip_rate 0.005`) 둘 다 좋은 먹이이므로 추적할 것이 없다. 관문 실패는 "진화가 학습을 찾지 못했다"가 아니라 **학습할 대상이 없었다**는 뜻이다.

**따라서 이 등록의 관문 결과와 `PROTOCOL_ETA`의 결과는 가설에 대한 판정이 아니다.** 연구 로그 43-1과 공개 README의 "진화는 학습을 쓰지 않았고, 학습률을 심으면 적합도가 떨어졌다"는 서술은 철회한다.

원인: §2가 생태 파라미터 13개를 동결하면서 탐색이 암묵적으로 고정한 독 확률을 빠뜨렸고, 드라이버가 명시하지 않은 인자에 엔진 기본값을 썼다. 드라이버의 학습 분기는 이 수정 이후 실행을 거부하도록 막았다. 재시도하려면 독 확률을 명시한 새 등록이 필요하다.
