### 계기: 대조군의 감각→운동 지름길 (결함 29)
`check_shortcuts.py`(0세대 배선, 10시드, `results/shortcut_check.txt`): 커넥톰은 후각 감각 출력 중 하행(운동) 뉴런으로 직행하는 비율 0.0001, 최단 경로 3단계. N1·N2는 그 비율 약 0.107, N3 0.063, 최단 경로 1단계(직행). 실제 파리의 후각 수용체 뉴런은 하행 뉴런에 직접 연결되지 않는다. 무작위 대조군은 생물학적으로 불가능한 냄새→운동 직통선을 가졌고, 진화는 이를 이용해 냄새 추적을 쉽게 발달시켰다 — 대조군의 후각 의존과 빠른 개선을 설명하는 구조적 불공정. 지금까지의 "대조군이 커넥톰을 추월"은 이 교란을 포함한다.

### 새 대조군 (엔진에 추가, 나머지 불변)
- **N4 인터페이스 보존 연결 수 보존**: 감각 그룹에서 나가는 간선과 하행 뉴런으로 들어가는 간선(에이전트의 입출력 인터페이스)은 커넥톰 그대로, 나머지 내부 간선만 Maslov–Sneppen 교환(내부 입·출 연결 수 보존). PN→KC는 N2 규칙.
- **N5 인터페이스 보존 열 셔플**: 인터페이스는 그대로, 각 비감각 출발 그룹의 내부 출력을 내부 대상(비감각·비하행) 중 무작위 위치로 이동. PN→KC는 N2 규칙.
- 생성 시점 검증을 엔진에 넣음(인터페이스 최대 차이 0이 아니면 중단). 시드 3 확인: 인터페이스 차이 0, 간선 14,989개 유지, 내부 간선 중첩 N4 0.116 · N5 0.095, 지름길 비율 0.0001·경로 3단계로 커넥톰과 동일.
