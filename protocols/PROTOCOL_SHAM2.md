# 사전 등록 — 용량별 재배선 일치 대조 (2026-09-22, 실행 전 동결)

엔진 `evo_learn.py` sha256 앞 16자리 `5500b05bfc45db51`. 뇌 데이터 `2781469e0524f33c`.

## 계기

`PROTOCOL_DOSE.md` 격자에서 용량-반응(D1)은 지지됐으나 재배선 일치 대조는 **최대 용량에만** 있었다. SHAM은 전체 이식에 필요한 교환 횟수(101회)로 만들어졌고 AS10이 100회를 썼으므로 그 짝만 맞았다. 중간 용량 AS1·AS3·AS5(17·28·44회)에는 짝이 없어, 그 구간의 상승이 지름길 때문인지 교환 횟수 때문인지 분리되지 않는다. 논문 §3.5가 이 한계를 스스로 적었다.

이 등록은 그 구멍 하나만 메운다.

## 설계상의 수정 (중요)

직전 격자의 SHAM은 교환 예산을 **별도 난수 스트림**(`default_rng(777)`)으로 계산했다. AS 조건은 시드별 스트림 `nrng`로 이식하므로, 같은 목표 비중이라도 도달에 필요한 교환 횟수가 달라진다. 실측 확인 결과 시드 0에서 AS1은 17회, 같은 방식으로 만든 SHAM1은 7회로 **짝이 맞지 않았다**.

엔진을 고쳐 `SHAM<pct>`가 **같은 실행에서 `AS<pct>`가 실제로 쓴 교환 횟수를 그대로** 받게 했다(`AS_SWAPS` 표). 따라서 `--conds`에서 각 AS가 짝 SHAM보다 먼저 와야 하며, 엔진이 이를 단언으로 강제한다. 수정 후 시드 0 실측: AS1/SHAM1 = 17/17, AS3/SHAM3 = 28/28, AS5/SHAM5 = 44/44.

## 조건

```
A       커넥톰
AS1     지름길 비중 1%로 올림   (시드별 n1 회 교환)
SHAM1   교환 n1 회, 출발이 후각수용체가 아니고 도착이 하행그룹이 아닌 간선 쌍만
AS3     3%                      (n3 회)
SHAM3   교환 n3 회
AS5     5%                      (n5 회)
SHAM5   교환 n5 회
```

7조건 × 512 = pop 3584. AS10/SHAM101 짝은 직전 격자에 이미 있으므로 넣지 않는다.

**짝을 같은 실행 안에 두는 것이 핵심이다.** 같은 시드, 같은 난수 스트림, 같은 세계에서 진화해야 짝지은 검정이 성립한다. 별도 격자로 돌려 비교하면 실현치 간 변동이 효과에 섞인다.

## 설계

생태 P0T0·P1T0(기존과 동일), 시드 0~9, 600세대, 결함 28 수정 엔진, global 보정. 평가·통계는 `PROTOCOL_ECO`와 동일(공통정원 probe, 마지막 probe = 550세대). 20실행.

## 사전 예측

- **S1 (주)** 각 용량에서 (AS − SHAM)이 양수다. 세 용량 각각 짝지은 Wilcoxon, Holm 보정, 두 생태 평균. 셋 중 **둘 이상**에서 p_holm < 0.05이면 지지.
- **S2** (AS − SHAM)이 지름길 비중에 단조 증가한다. Page 검정 p < 0.05.
- **S3** SHAM 자체의 대 커넥톰 효과는 교환 횟수에 무관하다. (SHAM1, SHAM3, SHAM5) − A 에 대한 Page 검정이 유의하지 않다(p >= 0.05).
- **S4 (음성 대조)** 0세대에서는 조건 간 차이가 검출되지 않는다.

## 해석 규칙 (결과를 보기 전에 고정)

| 결과 | 원고에 쓰는 것 |
|---|---|
| S1·S2 지지 | 교환 횟수를 맞춰도 지름길이 용량에 비례해 효과를 낸다. §3.5의 잔여 교란이 해소됐다고 적고 한계 문장을 뺀다 |
| S1 지지·S2 기각 | 지름길이 효과를 내지만 용량 비례는 확인되지 않았다. 최대 용량 비교만 남긴다 |
| S1 기각 | 중간 용량의 상승은 지름길이 아니라 재배선 양으로 설명된다. §3.5의 용량-반응 주장을 최대 용량 비교로 축소하고, 직전 격자의 D1을 재해석해 적는다 |
| S3 기각 | SHAM 효과가 교환 횟수에 의존한다 — 재배선 일반의 효과가 양에 비례한다는 뜻이므로 그대로 보고한다 |

S1이 기각되면 논문의 주장 하나가 줄어든다. 그래도 그대로 싣는다.
